0.1 Forecasting and Warning Data and Digital Asset Governance

The Forecasting and Warning team operates a complex set of flood models, data pipelines, and code tools that collectively underpin operational Flood Incident Management. As the team and its technical environment have grown, a clear gap has emerged: there is no consistent, documented framework governing how these assets are built, managed, or handed over.

This has practical consequences. Models are updated without version records. Code tools lack owners, documentation, or tests. Hydrometric data enters pipelines without a traceable audit trail. When a team member leaves or moves on, knowledge leaves with them. When a tool fails, there is no standard process for understanding what went wrong or how to fix it.

The absence of governance also creates a compliance risk. The team’s assets and outputs are used to inform real decisions during flood events. Without documented quality standards, provenance tracking, and role accountability, it is difficult to demonstrate that those outputs are fit for purpose.

This work establishes a governance framework to address these gaps. It sets out clear roles and responsibilities, defines quality standards for data and models, and establishes proportionate rules for code development and tool promotion. The aim is not to add bureaucracy, but to give the team a shared foundation: one that supports reproducible outputs, safe handovers, and confident operational delivery.
